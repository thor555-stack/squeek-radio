SQUEEK RADIO

Live generative music, played by Squeektoshi's wheel on Squeekchain.
wheel … rpm … block … round … distance …
How it plays
• Wheel running: tempo follows the real RPM, faster run = faster arpeggio and brighter filter.
• Wheel resting: a slow sleep drone with soft breathing pads, naps are music too.
• New Squeek block: a bell chime. New settled round: a deep bass drop.
• Every note is seeded from the live block and work counter, so each run is its own song.
Stream overlay
Add a Browser Source in OBS with this page plus ?overlay=1. Transparent background, wheel and status only. Add &autoplay=1 and tick "Control audio via OBS" to stream the music. Data refreshes every 5 seconds from the public Squeekchain API.
